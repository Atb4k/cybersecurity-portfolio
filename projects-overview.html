CISCO IOS · PACKET TRACER

Enterprise Network Security

Security improvements to a simulated multi-department network: extended ACLs, SSHv2 management restrictions, and switch port security on a selected Administration access port.

Key results

  • Reception-to-CEO ping blocked following ACL configuration
  • Authorised Administration SSH permitted while Reception SSH refused
  • Replacement device triggered a security violation on Fa0/13
